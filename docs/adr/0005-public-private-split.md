# ADR-0005: Open source and deployment boundary

Status: accepted

KOKUTBON maintains the complete source in this repository under Apache-2.0. Everyone may reuse it, including commercially, under that license. Funding does not buy exclusive features or governance. This supersedes the former private commercial extension plan.

The supported reference deployment uses simulated points (PTS). Provider agreements, private operational credentials and real user data are deployment inputs and do not belong in source. Source licensing does not supply gambling, payment, data or trademark rights.

Database migrations 001–005 implement the current points pilot; see [the runbook](../points-pilot-runbook.md). Other demonstration modules must not be confused with approved live integrations.
